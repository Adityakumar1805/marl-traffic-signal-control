How to read this page

  • Two grids, the same traffic. The same vehicles enter both grids at the same moments. Green is the RL Agent System (four learning agents, one per junction); grey is the Traditional Traffic System (a fixed 30 s timer per direction).
  • Lower is better for waiting time and queues; higher is better for trips completed.
  • Emergency vehicles (🚨 button): choose an ambulance, a police car or a fire engine; the same vehicle enters both grids. It is circled on both maps with a label saying whether it is moving, waiting or not moving (no progress for 30 s), the light it waits at is ringed and its route ahead is dashed. The line above each map says the same in words, and the tracker under the maps shows which system is ahead, every junction and how long it took to get through. When it waits too far back in a long queue to be drawn, a dashed circle marks that queue's +n badge. Timeline lists every step.
  • Safety first: both systems must show a 3 s amber and a 2 s all-red at every change, even for an emergency vehicle.
  • Shared demo: everyone watching sees the same run and the same button presses.
